## 🎯 About

**LUXE GLOW** is a clean beauty & skincare e-commerce UI featuring a complete shopping and authentication experience. With a soft, premium aesthetic, it showcases clean formulas and ethical beauty products across multiple beautifully crafted pages.

---

## 🌟 Pages

| Page | Description |
|------|-------------|
| `index.html` | Hero landing & featured collections |
| `products.html` | Full product catalog |
| `about.html` | Brand story & values |
| `contact.html` | Customer support form |
| `login.html` | User login interface |
| `signup.html` | New user registration |
